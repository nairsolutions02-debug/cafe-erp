1One-time setup (only once ever)

Already done for your first cafe. Check this only if you're on a new laptop or account.

  • GitHub repo: nairsolutions02-debug/cafe-erp exists and has the latest code on main.
    Open repo
  • Vercel can see the repo. The Vercel GitHub App must be installed on nairsolutions02-debug with access to cafe-erp. Signing in to Vercel with GitHub is not enough.
    GitHub → Installed apps → Vercel → Configure
  • Supabase account (log in with GitHub or email).
    Supabase dashboard
  • Vercel Pro before the first paying cafe (the free Hobby plan doesn't allow commercial use). One Pro team holds all cafes.
    Vercel dashboard
  • 2-factor login on GitHub, Vercel and Supabase. These accounts control every cafe's data.
  • Password manager (Google Password Manager / Bitwarden) to save each cafe's Supabase DB password and owner login.

2Collect from the cafe owner

Before or at the visit · 10 min of talking

  • Cafe name exactly as on their board, plus a one-line tagline.
  • Owner's email: becomes the admin login. Must be one they can open.
  • Logo: square PNG/JPG, ideally 512×512 (WhatsApp it to yourself).
  • Brand colour (from logo/board). Pick the hex code e.g. #2E7D32.
  • Address, phone, opening hours, Instagram link.
  • GSTIN (if registered) and GST rate. Most cafes: 5% (2.5% CGST + 2.5% SGST). Not registered: 0%.
  • Full menu with prices: photo of the menu card is enough. Note veg / non-veg.
  • Number of tables and how they're numbered (1, 2, 3… or A1, A2…).
  • Photos of 5–10 bestsellers (optional; can be added later from admin).

4Create the Supabase project

3 min (+2 min waiting)

  • Open New project and pick your organization.
  • Project name: cafe-name (lowercase, dashes).
  • Database password: tap Generate a password → copy → save in your password manager as "Cafe Supabase DB". You won't need it day to day, but you can't see it again.
  • Region: South Asia (Mumbai), fastest for Indian customers.
  • Plan: Free to start (see Costs, max 2 free projects per account). Tap Create new project and wait until the dashboard shows the project is ready (~2 min).
  • Copy the Project URL and the Publishable key into Cafe details.
    Settings → API Keys
    Project URL is on the project's home page (Connect button) and looks like https://abcd1234.supabase.co. Use the Publishable key (sb_publishable_…). Never copy the secret key (sb_secret_…) anywhere.

6Login settings

  
1 min

  
    
    
  • Open Authentication → Sign In / Providers
    • 
    
  • Turn ON "Allow anonymous sign-ins" → Save. This is how customers log in with just name + mobile.
    • 
    
  • Leave "Allow new users to sign up" ON, and leave the Email provider enabled.
      
    Don't turn these off. Turning off sign-ups also blocks customer login, and turning off Email blocks the owner's admin login. This is safe: a stranger who signs up gets no admin access. Admin rights only come from the make_admin step below.
    • 
    
  • "Confirm email" can stay on; you'll create the owner's account pre-confirmed in the next step.
    •

12Test everything

  
5 min · use the owner's laptop/tablet for admin and your phone for customer

  
Admin and customer can't share one browser. Use two devices, or a normal + Incognito window. A browser logged in as admin shows "Signed in as admin" on customer pages.

  
    
    
  • Admin login: Open admin login → Owner email tab, with the owner's email + password → accept the terms once.
    • 
    
  • Staff & Roles: add one Cashier with a PIN; log in as them in Incognito (Phone + PIN) → they land on Orders and don't see Dashboard/Analytics.
    • 
    
  • Admin → Settings: restaurant name, address, GSTIN and taxes show what you set. Fix anything and Save.
    • 
    
  • Admin → Menu: items are there. Add a photo to 1 item to test uploads.
    • 
    
  • Leave Admin → Orders open.
    • 
    
  • Customer (phone): Open as Table 1 → enter name + mobile → straight in, no OTP.
    • 
    
  • Add 2 items → Cart shows "Table 1 - Your table" → Place Order.
    • 
    
  • Order appears on the admin screen within 1–2 seconds, without refreshing, with a sound.
    • 
    
  • Admin: Confirm → Start Preparing → Mark Ready → Mark Served. The phone updates each time.
    • 
    
  • Phone: Request Bill → Admin: Generate Bill (check name, GSTIN, tax lines) → Cash Paid → phone shows "Payment Received".
    • 
    
  • Admin → Dashboard shows today's revenue. Then cancel/ignore the test order. It's fine to leave it in history.
    •

16Troubleshooting

  

    
What you seeFix

    
Vercel build fails / "No package.json"Project → Settings → General → Root Directory = frontend → Redeploy.

    
cafe-erp missing in Vercel import listVercel GitHub App lacks access: GitHub → Installed apps → Vercel → Configure → add cafe-erp.

    
Site opens but menu empty, errors in consoleWrong VITE_SUPABASE_URL or key. Fix in Vercel → Settings → Environment Variables → then Deployments → ⋯ → Redeploy (env changes need a redeploy).

    
Customer login: "Anonymous sign-ins are disabled"Step 6: turn on anonymous sign-ins.

    
Customer login: "Signups not allowed for this instance"Step 6: turn "Allow new users to sign up" back ON.

    
Admin login: "Invalid credentials"Check email/password; reset it in Authentication → Users → ⋯ → Send password recovery, or delete and recreate the user (then run make_admin again).

    
Admin login: "Email logins are disabled"Authentication → Sign In / Providers → Email → enable.

    
Admin login: "This account is not an admin"Run the make_admin SQL (step 7) with the exact email.

    
Customer page shows "Signed in as admin"That browser is logged in as admin. Use another device/Incognito, or tap "Log out admin".

    
"Please sign in first" when orderingRefresh the page and log in again with name + mobile.

    
"This table is currently occupied"Another customer has an open bill on that table. Admin → Tables → Free Table if it's stale.

    
Orders only appear after refreshSetup SQL didn't finish: re-run the last part, or check Database → Publications → supabase_realtime includes orders and dining_tables.

    
Image upload failsMust be logged in as admin; image under 5 MB, jpg/png/webp/gif.

    
Wrong tax on billsAdmin → Settings → Tax Configuration. Applies to new orders only.

    
Supabase project "Paused"Free projects pause after 7 days without use. Open the project → Restore. Move busy cafes to Pro.

    
Setup SQL: "already exists"The setup was already run on this project. Nothing to do.

  

  
Still stuck: screenshot the screen + browser console (desktop: F12 → Console) and send it to Claude.







  
17Updates & maintenance

  
Website changes (all cafes at once)

  
Merge to main on GitHub → every cafe's Vercel project rebuilds automatically in ~1 minute.

  
Database changes (per cafe)

  
Each release is listed in RELEASES.md with its deploy steps and a test checklist. When a release ships a file in supabase/upgrades/ (e.g. 2026-10-phase0.sql, then 2026-10-phase1.sql), paste that one file into each cafe's SQL Editor and Run, oldest first, once each. It is wrapped in a transaction: it either applies fully or not at all. A new project doesn't need upgrades: the setup SQL above already includes them. Monthly check per cafe (5 min)

  
    
    
  • Supabase → Reports / Usage: database & storage well under plan limits (free: 500 MB DB, 1 GB files).
    • 
    
  • Backup: free plan → Database → Backups isn't automatic; export data occasionally (Table Editor → export CSV for orders) or use Pro (daily backups).
    • 
    
  • Clean up old anonymous logins (harmless, keeps the user list tidy). SQL Editor:
      
    delete from auth.users
 where is_anonymous
   and created_at < now() - interval '90 days'
   and id not in (select id from public.profiles where customer_id is not null);

18Turning on SMS OTP later

  
Customers log in with name + mobile only. The trade-off is that anyone typing someone else's number sees that person's history and points. To require OTP for a cafe:

  
    
    
  • Get a 2factor.in API key (prepaid SMS credits).
    • 
    
  • From the repo on your Mac:
      
    • 
    
  • SQL Editor: update public.settings set value = 'true' where key = 'otp_login_enabled';
    • 
    
  • Vercel → Environment Variables → add VITE_OTP_LOGIN = true → Redeploy.
